# Documents and signatures — local demo

Confirmed choices: unified upload with category selection, one file at a time, filename and upload date, newest first, multiple files per category. Right-side preview expands to full-screen layout. Document rows show an icon, display title, date on the right, and a Preview CTA with Download / Delete icon buttons. Preview opens Replace and Edit title. Main documents default to ID, Work Permit or Green Card; other documents require a custom display title. Original filenames remain internal for download and case references. Replacement confirms the display title, and deletion confirms before removal.

Actual file bytes are persisted in IndexedDB. Metadata remains in the existing client store. This is browser-local demo storage, not the desktop encrypted vault, production storage or cross-device sync. Legacy filename-only records remain visible and explain why preview/download is unavailable until replaced. PDF and common raster image formats preview; other files can be downloaded. Empty files and files exceeding 32 MiB are rejected. Replacing one record preserves other records in the category. Case evidence and follow-up filename links follow replacements; confirmed deletion clears affected links, preserving case dates.

Original implementation reviewed in DevLance112/Client-Management-System-SHE: casenote_app/signature_ui.py and signature_processing.py. The demo follows its draw/clear/preview/name/save workflow and uploaded PNG/JPEG/PDF region selection, page selection, coordinate adjustments, optional light-background removal and transparent PNG preview. Crops can be redrawn, dragged, resized with handles, numerically adjusted, or moved with arrow keys (Shift moves 10 pixels). CA signatures are browser-shared across clients; client/employer signatures remain client-specific. This saves signature assets; applying them to official generated forms still belongs to the later forms integration.

Validation: production build and 34 tests pass, including paper removal/empty-image errors, legacy records, replacement/deletion reference integrity and file-size guards. Browser verified the document list, preview actions and View more navigation to a full Documents page. Right panels use a top-right close icon. Approved for remote push.
